LOPEZ MENU - PUT THE WEBSITE ONLINE (only clicking, no Terminal)
=================================================================

This project is a Cloudflare PAGES project: a static site (public/) plus server code
(functions/api/*.js) that Cloudflare runs at /api/... . Pages compiles the functions/ folder
itself when it builds from GitHub. That is the method below.

Why not "Worker" or drag-and-drop: a Worker made by uploading files only serves the files
(so /api/likes gives 404), and drag-and-drop uploads also skip the functions/ folder.

The code is on GitHub:  ramyberrekiapro/BIVT-25-Lab-6,  branch  claude/affectionate-keller-n0mht4,
folder  lopez-site-download/lopez-site .


PART 1 - Create the Pages project from GitHub (once)
----------------------------------------------------
1. https://dash.cloudflare.com -> left menu "Workers & Pages" (maybe inside "Compute (Workers)").
2. Click "Create" -> tab "Pages" (or the link "Looking to deploy Pages? Get started").
3. Click "Connect to Git" / "Import an existing Git repository" -> "Get started".
4. Choose GitHub. If asked, click "Connect GitHub" / "Install & Authorize" and allow access to
   the repository  BIVT-25-Lab-6  (choosing "Only select repositories" is fine).
5. Select  BIVT-25-Lab-6  -> "Begin setup".
6. Fill in exactly:
     Project name:            lopez-menu
     Production branch:       claude/affectionate-keller-n0mht4
     Framework preset:        None
     Build command:           (leave empty)
     Build output directory:  public
     Root directory (under "Advanced" / "Root directory"):  lopez-site-download/lopez-site
7. Click "Save and Deploy". Wait for "Success" (1-2 minutes).
   The address is shown, e.g.  https://lopez-menu.pages.dev


PART 2 - Connect the database and the password
----------------------------------------------
Use the database you already created (lopez-db). Its data is kept.
1. Open the new project lopez-menu -> tab "Settings".
2. "Bindings" -> "+ Add" -> "D1 database":
      Variable name:  DB
      D1 database:    lopez-db
   -> "Save".
3. "Variables and Secrets" -> "+ Add":
      Type: Secret    Variable name: ADMIN_PASSWORD    Value: your password
   -> "Save".   (If asked Production/Preview: Production.)


PART 3 - Deploy again so the settings apply
-------------------------------------------
Tab "Deployments" -> on the latest deployment click "..." (three dots) -> "Retry deployment".
Wait for "Success".


PART 4 - Check
--------------
1. https://<your-address>.pages.dev/api/likes   -> shows  {"counts":{...}}
2. https://<your-address>.pages.dev/api/menu    -> shows  {"items":[...]}
3. https://<your-address>.pages.dev/admin/      -> sign in -> Messages, Menu, J'aime tabs load.
If /api/likes shows {"error":"database_not_configured"}: PART 2 step 2 is missing, or PART 3 not done.
Only when all of this works: delete the old Worker (Workers & Pages -> lopezmenu -> Settings ->
Delete). Nothing in the database is deleted with it.


UPDATES
-------
Every time Claude pushes a change to the branch above, Cloudflare publishes it automatically
(1-2 minutes). You never upload a ZIP again. Changes you make on the owner's page are stored in
the database and are kept.


USING THE OWNER'S PAGE  (https://<your-address>.pages.dev/admin/)
----------------------------------------------------------------
  Messages  - customer messages; mark as read or delete.
  Menu      - "Modifier / Edit" on any item: name, description (French and English), price,
              photo, or untick "Visible" to hide it -> "Enregistrer / Save".
              "+ Ajouter / Add" adds a new item to a category. Changes show within seconds.
  J'aime    - every item ranked by number of likes.

Good to know
  - Everything here is on Cloudflare's free plan.
  - Each visitor can send 5 messages per 10 minutes and like/unlike 60 times per 10 minutes.
  - 10 wrong passwords lock sign-in for 15 minutes.
  - No phone notification for new messages; open the owner's page to check.
  - Change the password: Settings -> Variables and Secrets -> edit ADMIN_PASSWORD, then PART 3.


For developers: public/ = site, functions/ + lib/ = Pages Functions (D1 binding DB, secret
ADMIN_PASSWORD). tools/build.py rebuilds public/menu-data.json. tools/make_upload.py builds a
dashboard-upload ZIP with a compiled _worker.js (alternative to the GitHub method; not used now).
